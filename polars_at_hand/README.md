# Polars at Hand 

This directory serves as a dedicated environment for exploring Polars query planning, lazy evaluation, and interactive data engineering.

## Getting Started

This repository uses Git Submodules to manage external resources and guides. If you have just cloned the parent repository, the submodules will initially be empty.

To fetch the content and stay up to date, run:

```bash
# Initialize and pull the submodule content
git submodule update --init --recursive

# To pull the latest changes from the upstream fork later:
git submodule update --remote --merge
```
